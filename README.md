# Рассрочка с отправкой в МойСклад

## Важно про GitHub Pages

GitHub Pages для этого приложения не подходит. Он умеет отдавать только статические файлы и не запускает `server.js`.

Это приложение требует Node.js-сервер, потому что:

- токен МойСклад должен храниться в `.env`, а не в браузере;
- товары, типы оплаты и сотрудники загружаются через сервер;
- розничная продажа и контрагент создаются через серверный API.

Если загрузить проект на GitHub Pages, вместо приложения может открыться этот `README.md`, потому что основной HTML лежит в `public/index.html`, а Pages ищет `index.html` в корне. Даже если показать интерфейс, кнопка создания продажи не заработает без Node.js-сервера.

Для публикации используйте Render, Railway, VPS или другой Node.js-хостинг.

Небольшое веб-приложение считает итоговую цену рассрочки и создает розничную продажу в МойСклад.

Пример:

- Товар: `100000`
- Банк: `MBank`
- Срок: `6 мес`
- Итог: `90000`
- Комиссия: `10000`

## Запуск

```bash
cp .env.example .env
npm run dev
```

Откройте `http://localhost:3000`.

## Деплой на Render

1. Создайте Web Service.
2. Подключите GitHub-репозиторий.
3. Укажите:

```text
Build Command: npm install
Start Command: npm start
```

4. В Environment Variables добавьте все значения из локального `.env`.

Не добавляйте `.env` в GitHub. В проекте уже есть `.gitignore`, который скрывает `.env`.

## Настройка МойСклад

Заполните `.env`:

- `MOYSKLAD_TOKEN` — токен API МойСклад.
- `MOYSKLAD_DOCUMENT_TYPE` — `auto`, чтобы полная оплата создавала розничную продажу, а рассрочка/смешанная оплата создавала отгрузку.
- `MOYSKLAD_ORGANIZATION_HREF` — ссылка `meta.href` вашей организации.
- `MOYSKLAD_AGENT_HREF` — ссылка `meta.href` контрагента.
- `MOYSKLAD_STORE_HREF` — запасной склад, если он не подтянулся из точки продаж.
- `MOYSKLAD_RETAIL_STORE_HREF` — запасная точка продаж, если она не выбрана в интерфейсе.
- `MOYSKLAD_ASSORTMENT_HREF` — товар или услуга, которую приложение добавит в документ.
- `MOYSKLAD_ASSORTMENT_TYPE` — тип позиции, обычно `product` или `service`.
- `MOYSKLAD_STATE_HREF` — необязательный статус документа.
- `MOYSKLAD_RETAILDEMAND_PAYMENT_TYPE_ATTRIBUTE_HREF` — доп.поле продажи `Тип оплаты`.
- `MOYSKLAD_RETAILDEMAND_EMPLOYEE_ATTRIBUTE_HREF` — доп.поле продажи `Сотрудник`.
- `MOYSKLAD_RETAILDEMAND_RECEIVABLE_ATTRIBUTE_HREF` — доп.поле продажи `К поступлению`.
- `MOYSKLAD_RETAILDEMAND_COMMISSION_ATTRIBUTE_HREF` — доп.поле продажи `Комиссия банка`.

Цена в позицию отправляется обычная, без вычета комиссии. Комиссия банка отправляется отдельным доп.полем.

В режиме `auto`:

- если товар полностью оплачен сразу, создается `Продажа` (`retaildemand`);
- если есть банк, рассрочка или смешанная оплата с остатком, создается `Отгрузка` (`demand`).

## Где менять проценты

Основной вариант: укажите процент в комментарии типа оплаты в МойСклад.

Примеры комментария:

- `10`
- `10%`
- `комиссия 10`
- `ставка: 0.10`

Если комментарий пустой, приложение берет запасные ставки из `server.js` в объекте `paymentRateRules`.

```js
M+: {
  3: 0.05,
  6: 0.10,
  12: 0.20
}
```

Для `100000`, `MBank`, `6 мес` ставка `0.10` даст комиссию `10000` и итог `90000`.
