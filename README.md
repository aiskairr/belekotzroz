# Ordo CRM

Ordo CRM — локальная Node.js CRM для продаж, отчетности и учета, связанная с МойСклад, Supabase и дополнительными сервисами. Приложение работает через сервер `server.js`; GitHub Pages не подходит, потому что статический хостинг не умеет безопасно хранить токены и выполнять серверные API-запросы.

## Быстрый запуск

```bash
cp .env.example .env
npm install
npm start
```

Откройте:

```text
http://localhost:3000
```

Для перезапуска локального сервера:

```bash
lsof -ti:3000 | xargs kill
npm start
```

## Вход и роли

Сотрудники заходят через стартовую страницу `http://localhost:3000`. Список сотрудников загружается из CRM/Supabase и резервных логинов из `.env`.

Основные роли:

- `admin` — полный доступ ко всем разделам.
- `owner` — полный рабочий доступ, отчеты, сотрудники, аудит.
- `manager` — продажи, доставки, отчеты, зарплаты, документы, таможня.
- `seller` — продажи, доставки, отчеты и документы.
- `accountant` — отчетность, расходы, зарплаты, расчет цен, таможня.
- `logistics` — продажи, долг, доставки и документы.
- `employee` — базовый доступ к продажам и доставкам.

Права и сотрудники настраиваются в разделе **Сотрудники и доступ**.

## Основные разделы

**Продажи** — оформление обычной продажи. Выберите филиал, найдите товар, добавьте позиции, укажите оплату, клиента и создайте документ в МойСклад.

**Продать в долг** — отдельный режим для исключительных продаж в долг. Фото чека в этом режиме необязательно.

**Доставки** — учет доставок по клиенту, адресу, дате и статусу.

**Отчетность** — отчеты по продажам, прибыли, клиентам и документам.

**Банковские комиссии** — контроль оплат, комиссий банков и расхождений.

**Расходы** — учет операционных расходов бизнеса.

**Зарплаты** — расчет зарплат и начислений сотрудникам.

**Счета юрлицам** — создание Word/PDF счетов и документов для юридических лиц.

**Расчет цен** — массовый расчет и обновление цен в МойСклад.

**Калькулятор таможни** — расчет себестоимости партии по товарам, весу, объему и общим расходам.

**Журнал действий** — аудит важных действий пользователей.

**О системе** — справочная страница проекта.

## Как оформить продажу

1. Откройте **Продажи**.
2. Выберите филиал: `Аю-Гранд` или `Беш-Сары`.
3. В поле поиска найдите товар по названию, коду или артикулу.
4. Нажмите на найденный товар или кнопку **Добавить товар**.
5. Проверьте цену и количество.
6. Выберите тип оплаты, сотрудника и клиента.
7. При необходимости заполните доставку и фото чека.
8. Нажмите кнопку создания документа.

Цена товара на странице продаж берется из типа цены МойСклад `3-6` / `Цена 3-6м`, заданного переменной:

```text
MOYSKLAD_PRODUCT_PRICE_NAME=3-6
```

Если у товара нет цены этого типа, в продажах будет `0`, чтобы сразу было видно, что цена 3-6 не заполнена в МойСклад.

## Оплаты и документы

Поведение задается переменной:

```text
MOYSKLAD_DOCUMENT_TYPE=auto
```

В режиме `auto`:

- полная оплата сразу создает розничную продажу `retaildemand`;
- рассрочка, долг или смешанная оплата с остатком создают отгрузку `demand`.

Комиссии банков берутся из комментариев типов оплаты в МойСклад. Поддерживаются форматы:

- `10`
- `10%`
- `комиссия 10`
- `ставка: 0.10`

Если комментарий пустой, сервер использует резервные правила из `server.js`.

## Калькулятор таможни

Откройте **Калькулятор таможни**.

1. Укажите курс USD → KGS.
2. Добавьте товары вручную или через поиск МойСклад.
3. Для каждого товара заполните количество, тип коробки, вес, объем, закупку и прочие расходы.
4. В блоке **Общие расходы партии** заполните растаможку, СВХ, декларацию, оформление, пломбу, сопровождение и транспорт.
5. Выберите распределение общих расходов: по весу или по объему.
6. Итоговая таблица покажет цену за товар, объем и сумму.

История расчетов сохраняется в Supabase. `owner` и `admin` видят историю всех пользователей, остальные пользователи видят только свои записи.

## Расчет цен

Раздел **Расчет цен** загружает каталог из МойСклад и позволяет считать:

- оптовую цену;
- цену `3-6`;
- цену `9-12`.

Перед сохранением проверьте выбранные типы цен и курс USD. Массовое сохранение обновляет цены в МойСклад и пишет действие в журнал аудита.

## Сотрудники и доступ

Раздел **Сотрудники и доступ** управляет:

- логинами сотрудников;
- ролями;
- филиалами;
- активностью пользователя;
- правами на разделы.

После изменения прав сотруднику может понадобиться выйти и войти заново.

## Важные настройки `.env`

Минимально нужны:

```text
PORT=3000
MOYSKLAD_TOKEN=...
MOYSKLAD_DOCUMENT_TYPE=auto
MOYSKLAD_ORGANIZATION_HREF=...
MOYSKLAD_AGENT_HREF=...
MOYSKLAD_STORE_HREF=...
MOYSKLAD_RETAIL_STORE_HREF=...
MOYSKLAD_PRODUCT_PRICE_NAME=3-6
CRM_SESSION_SECRET=...
SUPABASE_URL=...
SUPABASE_SERVICE_ROLE_KEY=...
```

Для двух филиалов можно задать отдельные аккаунты МойСклад:

```text
MOYSKLAD_AYU_TOKEN=
MOYSKLAD_AYU_ORGANIZATION_HREF=
MOYSKLAD_AYU_AGENT_HREF=
MOYSKLAD_AYU_STORE_HREF=
MOYSKLAD_AYU_RETAIL_STORE_HREF=

MOYSKLAD_BESH_TOKEN=
MOYSKLAD_BESH_ORGANIZATION_HREF=
MOYSKLAD_BESH_AGENT_HREF=
MOYSKLAD_BESH_STORE_HREF=
MOYSKLAD_BESH_RETAIL_STORE_HREF=
```

Не добавляйте `.env` в GitHub.

## Supabase

Supabase используется для CRM-пользователей, настроек интерфейса, расходов, доставок, бонусов и истории калькулятора таможни.

Проверьте, что в `.env` заполнены:

```text
SUPABASE_URL=
SUPABASE_SERVICE_ROLE_KEY=
```

SQL-схемы лежат в `loyalty-lab/*.sql`.

## Деплой

Для Render/Railway/VPS нужен Node.js-хостинг.

Render:

```text
Build Command: npm install
Start Command: npm start
```

В Environment Variables добавьте значения из `.env`. Не публикуйте реальные токены в репозитории.

## Что делать при проблемах

**Товар не находится** — проверьте токен МойСклад, филиал, название/код товара и доступ к складу.

**Цена в продаже 0** — проверьте, что у товара заполнена цена типа `3-6` / `Цена 3-6м` в МойСклад.

**Документ не создается** — проверьте `MOYSKLAD_ORGANIZATION_HREF`, `MOYSKLAD_AGENT_HREF`, `MOYSKLAD_STORE_HREF`, `MOYSKLAD_RETAIL_STORE_HREF` и права токена.

**История или расходы не сохраняются** — проверьте `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` и наличие таблиц.

**В браузере старый логотип или старый интерфейс** — сделайте hard refresh: `Cmd + Shift + R`.
