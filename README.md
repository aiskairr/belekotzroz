# Рассрочка с отправкой в МойСклад

Небольшое веб-приложение считает итоговую цену рассрочки и создает документ в МойСклад.

Пример:

- Товар: `100000`
- Банк: `MBank`
- Срок: `6 мес`
- Итог: `110000`
- Комиссия: `10000`

## Запуск

```bash
cp .env.example .env
npm run dev
```

Откройте `http://localhost:3000`.

## Настройка МойСклад

Заполните `.env`:

- `MOYSKLAD_TOKEN` — токен API МойСклад.
- `MOYSKLAD_DOCUMENT_TYPE` — `customerorder` для заказа покупателя или `demand` для отгрузки.
- `MOYSKLAD_ORGANIZATION_HREF` — ссылка `meta.href` вашей организации.
- `MOYSKLAD_AGENT_HREF` — ссылка `meta.href` контрагента.
- `MOYSKLAD_STORE_HREF` — склад, обязателен для отгрузки.
- `MOYSKLAD_ASSORTMENT_HREF` — товар или услуга, которую приложение добавит в документ.
- `MOYSKLAD_ASSORTMENT_TYPE` — тип позиции, обычно `product` или `service`.
- `MOYSKLAD_STATE_HREF` — необязательный статус документа.

Цена в позицию отправляется уже итоговая: товар + комиссия банка.

## Где менять проценты

Ставки находятся в `server.js` в объекте `banks`.

```js
MBank: {
  terms: {
    3: 0.05,
    6: 0.10,
    9: 0.15,
    12: 0.20
  }
}
```

Для `100000`, `MBank`, `6 мес` ставка `0.10` даст комиссию `10000` и итог `110000`.
