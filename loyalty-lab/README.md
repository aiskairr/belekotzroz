# Loyalty Lab

Отдельная тестовая папка для системы лояльности. Основное приложение МойСклад не меняется.

## Что умеет

- искать клиента по телефону;
- создавать клиента;
- показывать баланс бонусов;
- начислять бонусы от суммы продажи;
- списывать бонусы;
- показывать историю операций.

## Настройка Supabase

1. Создайте новый проект Supabase.
2. Откройте `SQL Editor`.
3. Выполните весь файл `schema.sql`.
4. Скопируйте `.env.example` в `.env`.
5. Заполните:

```env
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
LOYALTY_DEFAULT_PERCENT=3
```

`SUPABASE_SERVICE_ROLE_KEY` должен быть только на сервере. В браузер его вставлять нельзя.

## Запуск

```bash
cd loyalty-lab
npm run dev
```

Откройте `http://localhost:3100`.

## Как потом соединять с основным приложением

После создания продажи в МойСклад можно отправлять в эту систему:

- телефон клиента;
- ФИО клиента;
- номер документа МойСклад;
- сумму продажи;
- процент бонуса.

Для списания бонусов перед созданием продажи нужно сначала проверить баланс клиента, списать бонусы, а сумму списания учесть как скидку или отдельную строку в комментарии документа.
